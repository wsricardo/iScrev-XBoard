# iScrev-XBoard - Versão 2.0

Este diretório é dedicado ao planejamento, refatoração, análise do projeto e especificações para a versão **2.0** do **iScrev-XBoard**.

## Escopo e Conteúdo

- **Análise do Projeto:** Mapeamento da estrutura atual, identificação de gargalos, débitos técnicos e oportunidades de melhoria.
- **Refatoração:** Reestruturação e modernização do código-fonte para maior manutenibilidade, modularidade e performance.
- **Especificações da v2.0:** Documentação técnica contendo requisitos funcionais e não-funcionais, definição de arquitetura, padrões de projeto e roadmap de novas funcionalidades.
